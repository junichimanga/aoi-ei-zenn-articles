## 「自動化を推進するキャラ」が、やめた

口癖は「非効率は罪よ。」

Instagramに毎日投稿。HeyGenで動画を量産。メルマガをAIで自動生成。
全部、システム化して回していた。

でも、やめた。
3つのワークフローを、自分でつぶした。

失敗だとは思っていない。
観測した。判断した。選び直した。それだけ。

自動化は目的じゃない。
「ラクに、正確に、続けること」が目的。
そこを混同すると、自動化のために自動化を守り続けることになる。
気づいた時点でやめる。それだけのこと。

## 観測ノート①：Instagram「完全無人投稿」をやめた

### やっていたこと

Instagramへの投稿を、ほぼすべて自動化していた。

| ステップ | 担当 |
|---|---|
| 台本生成 | Claude（AI） |
| 動画生成 | HeyGen（AI） |
| 字幕合成 | Whisper＋Remotion |
| 投稿 | Instagram Graph API |
| キャプション・ハッシュタグ | Claude（AI） |

人間（私）が触るのは「最初のテーマ指定」だけ。あとは全部流れる。週7本、毎朝7時に自動投稿。

### なぜやめたか

「流れている」のに、なにも起きなかった。

フォロワーは増えていた。いいねも来ていた。
でも、コメントがなかった。DMがなかった。
なにより、**自分がそのアカウントに愛着を持てなくなっていた。**

ある日、自分の投稿を見ていて気づいた。
「これ、私が言いたかったことじゃないかもしれない。」

AIが生成した台本。AIが整えたキャプション。AIが選んだハッシュタグ。
全部、「蒼井詠っぽい言葉」で揃っている。
でも、蒼井詠の「今」じゃない。

自動化が、発信のリアルタイム性を殺していた。
これが、やめた理由。

### 代わりにしていること

週1回、30分だけ「手動チェックの時間」を設けた。

やること：

- 先週の投稿を3本、自分で読み直す
- 「本当にこれ言いたかった？」を問う
- 修正が必要なら、次週のテーマを手書きで1行メモ

週7本の投稿は週2本に減らした。
残り5本分の時間は、コメントへの返信とストーリーズの手書き更新に使っている。

### 筆者の観測

量を減らしたあと、コメントが届くようになった。DMも、少しだが来るようになった。

「量」より「温度」のほうが、読者に届く可能性がある。
これは筆者の個人的な観測であり、アカウントのジャンルや規模によって傾向は異なる。

> 📝 **観測メモ**
> 完全自動化の落とし穴は「誰も見ていない発信」になること。
> 自動化ツールは「手を動かす仕事」を代替する。「見る目」は代替しない。

## 観測ノート②：HeyGen×Remotion「毎日量産」をやめた

### やっていたこと

AIアバター動画（HeyGen）とテキストアニメーション動画（Remotion）を組み合わせ、毎日1本の動画を生成・投稿していた。

製作フロー（当時）：

```
テーマ指定 → Claude台本生成 → HeyGenで動画生成
         → Whisper字幕取得 → Remotionで字幕合成 → 自動投稿
```

実質の人的作業：台本確認5分＋仕上がり確認5分。生成中の待機30分を除けば約10分/本（筆者環境）。

### なぜやめたか

2つの問題が重なった。

**問題1：クオリティの均質化**

毎日出すために、台本をAIに任せる割合が増えた。
「まあこれでいいか」の積み重ね。どれも似たような仕上がりになった。
「これ見たことある」と自分で思う動画を、毎日出していた。

**問題2：コストがプランの設計と合わなくなった**

HeyGenのCreatorプランはクレジット制。
Avatar IVを使うと、1分あたり20クレジット消費する。
毎日量産していたら、月のクレジットがあっという間に底をついた。

**本質的な原因：「出すこと」が目的になっていた**

毎日投稿するために作っていた。作りたいものを作っていなかった。
目的と手段が逆転した状態。気づくのが遅かった。

### 代わりにしていること

週2本に絞った。選定基準も変えた。

**動画を作る前に答える3問（手書きで）：**

1. このテーマ、今週の自分が一番話したいか？
2. 見た人が「やってみよう」と思える具体性があるか？
3. 似たような動画を最近出していないか？

3問すべてにYESのテーマだけ動画化する。
NOが1つでもあれば、テキスト投稿かストーリーズに回す。

### 筆者の観測

週2本に絞ったあと、1本あたりの保存数が増える傾向があった（筆者アカウント観測）。
量が減り、1本への注意が増えた可能性がある。
ただし、フォロワー規模・ジャンル・投稿タイミング等の変数も同時に変わっているため、これだけが要因とは断定できない。

> 📝 **観測メモ**
> 「毎日作れる仕組み」と「毎日作るべき理由」は別の話。
> 仕組みが整ってからこそ、「何を作るか」の判断が重要になる。

## サンプルの読み方・使い方

この2つの観測ノートは、「自分の自動化を点検する素材」として使える。

読み方の提案はシンプル。
今動かしている自動化フローを1つ思い浮かべる。
そこに「自分の目が入っているか？」を問う。
入っていないなら、どこかに1箇所だけ手動チェックを足す。

それだけでいい。全部やめる必要はない。
「選び直す」のが目的であって、「壊す」のが目的じゃない。
