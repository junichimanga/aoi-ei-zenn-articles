# Claudeにメルマガを90日書かせた観測ノート【無料サンプル2個公開】

## この記事でわかること

- Claudeが書いたメルマガで読者から「AIっぽい」と言われた回に共通していた4つのパターン
- 開封後の返信率が変わったBefore/After実例——冒頭文を3点だけ書き換えた場合
- 「完全Claude起草 / 人間リライト済み / 完全人間」3グループを90日観察して気づいたこと

---

## なぜ記録したのか

「AIにメルマガ書かせてみれば」と言われた。

懐疑的だった。読者に送る文章を、自分の代わりに機械に書かせる。どこか後ろめたさがあった。

それでも試した。90日間、Claudeに下書きを依頼し、自作の配信ツール（WordPressプラグイン）から送り続けた。送信ログ・開封数・クリック数・解除数を全件記録した。

「AIで書けばラク」という話をしたいわけじゃない。「どこで読者が離れ、どこで反応したか」を残したかった。そういう動機。

今回はその記録から、無料で公開できる部分を2つ出す。

## 観測の前提

| 項目 | 内容 |
|---|---|
| 観測期間 | 90日間（週2〜3本配信） |
| 総配信数 | 約230本 |
| 配信ツール | 自作WordPressプラグイン（Fumi Mail Studio） |
| Claude使用比率 | 全体の約80%がClaude下書きを使用 |

配信を3グループに分類して観察した。

| グループ | 定義 | 観察された傾向（筆者環境） |
|---|---|---|
| A：完全Claude起草 | Claudeの出力をそのまま送信 | 「丁寧だけど何か違う」という返信が複数 |
| B：人間リライト済み | Claude下書き→固有名詞・体験談・語尾を書き換え | 「読んだよ」「これ私もやってる」など個人的な返信 |
| C：完全人間 | Claude未使用、全文自分で執筆 | 誤字・脱線が最多。解除率は最も低い傾向あり |

> ⚠️ あくまで筆者一人の環境での観察記録。読者の属性・業種・配信頻度が異なれば結果も変わる。一般化するつもりはない。

## 【無料サンプル①】「AIっぽい」と言われた回の共通パターン

90日間で読者から直接「なんか機械っぽかった」と言われたのは7回。そのうち6回に共通点があった。

### パターン1：冒頭が「質問形式」から始まっている

```
例）「あなたは毎朝、何時間を"非生産的な作業"に費やしていますか？」
```

Claudeはよく冒頭に読者への問いかけを入れる。丁寧で読みやすい。ただし、これをそのまま使うと「ライティング講座のテキストみたい」という感想が来やすかった。

返信をもらえた回の冒頭を確認すると、ほぼ全て「出来事の話」から始まっていた。

```
「昨日、〇〇があって」
「先週ずっと気になってたこと、書いていい？」
```

自分のメルマガの冒頭、質問で始まっている回がいくつあるか。確認する価値はある。

---

### パターン2：文末の曖昧語尾が重なる

Claudeは語調を柔らかくするために婉曲表現を使いがち。1通の中に「〜ではないでしょうか」「〜かもしれません」「〜と思われます」が3回以上出てくると、筆者の配信ログでは離脱が早い傾向があった。

キャラクターが断定・体言止めなら、なおさら問題になる。Claudeの「丁寧な婉曲」はキャラクターと戦う。声が二重になる。

---

### パターン3：固有名詞がゼロ

```
❌「多くの方が悩まれているように、情報の整理は現代のビジネスパーソンにとって〜」
✅「先週、読者のAさんから『整理する前に諦める』って返信がきた。刺さった。」
```

「いつ・誰が・何と言った」が抜けると、文章は汎用品になる。AI生成文はここが抜けやすい。固有名詞を1つ入れるだけで、文章の体温が変わる。

---

### パターン4：件名が「ベネフィット三段重ね」になっている

Claudeに件名を考えさせると、マーケティング的に「正しい」件名が出てくる。

```
例）「生産性が上がる・時間が返ってくる・明日から使える3つの習慣」
```

こういう件名が続くと、読者が「また何か売られる」と感じる傾向があった。筆者環境での解除タイミングを観察したときの話。

返信が来た件名を振り返ると、「出来事を描写しているだけ」のものが多かった。

```
「昨日、失敗した話」
「やめてよかったかもしれないもの」
```

売ろうとしていない件名の方が、開いてもらえていた。筆者の体験として。

## 【無料サンプル②】Before / After——冒頭を3点だけ変えた

実際に「AIっぽい」と指摘された配信の冒頭を、リライト後と並べる。

### 事例：自動化の話

**Before（Claude起草そのまま）**

> 「あなたは毎日の業務の中で、繰り返し行っている作業に気づいていますか？多くのビジネスパーソンが、気づかないうちに同じ手順を何度も繰り返しています。」

**After（人間リライト）**

> 「先週、Excelのコピペを37回数えた。本当に数えた。その日の夜、ちょっと嫌な気持ちになった。」

変えたのは3点だけ。

1. **質問を出来事に変えた**（「あなたは〜？」→「先週〇〇があった」）
2. **数字を具体化した**（「繰り返し行っている」→「37回」）
3. **感情を1行入れた**（「嫌な気持ちになった」）

Afterの方が文字数は短い。情報量も少ない。それでも筆者環境では、Afterに近い書き方をした回の方が返信が来やすかった。

理由についての仮説は一つある。読者は「役に立つ情報」より「自分と同じ経験をしている人」に反応しやすい。ただし、これは筆者一人の観察であり、断言はできない。

## チェックリストとして使う方法

上記2つのサンプルは、そのまま「Claude下書きのチェックリスト」として機能する。

Claudeに下書きを出力させた後、送信前にこれだけ確認する。

- [ ] 冒頭が質問形式になっていないか
- [ ] 「〜ではないでしょうか」「〜かもしれません」が3回以上重なっていないか
- [ ] 固有名詞（いつ・誰・何と言った）が1つ以上入っているか
- [ ] 件名がベネフィット三段重ねになっていないか

このチェックをかけてからリライトに入ると、どこを直すべきか見当がつきやすくなる。少なくとも筆者の体験では、チェックなしで送った回との差を実感している。

カスタム方法は単純。自分のキャラクターや口調に反する語尾リストを1行加えるだけでいい。体言止めが口調の核なら「文末が名詞で終わっているか」を追加する。それだけ。
