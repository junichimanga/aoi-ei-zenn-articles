## なぜこのノートを書いたか

「AIで自動投稿」という情報は多い。  
成功報告も多い。  
数字は盛られる。失ったものは書かれない。

筆者はAIキャラクター「蒼井 詠」としてInstagramを運営している。  
テーマはAIと自動化。  
自動化を語るなら、自分が自動化するしかない。そう判断した。

30日、毎日Reelを出した。  
コードを書かずに。  
数字を毎日記録しながら。

再現性のある失敗ログが、世の中に少なすぎる。  
だから書いた。

この記事では、その記録から2つのサンプルを無料公開する。

## 無料サンプル①：自動化スタックの全体像

1本のReelが世に出るまで、7つのステップがある。

| ステップ | ツール | 操作の種類 |
|---|---|---|
| ① 動画生成 | HeyGen（Web画面） | 手動（クリック3回） |
| ② 動画URL取得 | HeyGen API | 自動 |
| ③ 字幕タイムスタンプ生成 | OpenAI Whisper | 自動 |
| ④ 字幕合成・書き出し | Remotion | 自動 |
| ⑤ 動画アップロード | Cloudinary | 自動 |
| ⑥ Instagram Reel投稿 | Instagram Graph API | 自動 |
| ⑦ WordPress下書き保存 | WordPress REST API | 自動 |

手動なのは①だけ。  
最初に仕組みを1回設定すれば、あとは毎日HeyGenの画面でURLをコピーして貼り付けるだけ。  
1本あたりの作業時間は2〜3分（筆者実測）。

### コスト（筆者環境・2025年4〜5月の実績）

| ツール | 月額コスト | 補足 |
|---|---|---|
| HeyGen | プラン内 | Creatorプラン年間契約 |
| Whisper | 約27円 | 30本 × 約90秒の場合 |
| Cloudinary | 無料 | 月の無料枠内 |
| Instagram Graph API | 無料 | 投稿のみ |

Whisperの字幕生成コストが1本あたり約1円。  
これが最も意外だった数字だった。

※ 動画の本数・尺・解像度が異なれば変わる。あくまで筆者環境での実測値。

## 無料サンプル②：30日間の週別データ

30日間、毎朝7時台に投稿を続けた。  
以下は週別のサマリー。

| 期間 | 平均再生数 | 平均保存数 | 字幕ズレ発生率（筆者目視） |
|---|---|---|---|
| 1週目（Day 1〜7） | 441 | 16 | 28% |
| 2週目（Day 8〜14） | 623 | 28 | 21% |
| 3週目（Day 15〜21） | 748 | 36 | 14% |
| 4週目（Day 22〜30） | 901 | 51 | 9% |

3つの傾向が見えた。

**① 保存数が先に動いた。**

再生数より保存数の伸び率が大きかった。  
字幕ありの動画は、ミュートで見ても内容が伝わる。  
「あとで見返したい」と思わせるのに、音声より字幕が効いた可能性がある。  
（仮説。継続検証中。断言はしない。）

**② 字幕ズレは「原稿の書き方」で減らせた。**

1週目に28%あったズレ発生率が、4週目には9%まで落ちた。  
ツールの精度が上がったのではない。  
原稿の書き方を変えた。具体的には——

- 固有名詞（ツール名）はカタカナで読みがなを補足
- 話速が上がりやすい文節は改行で分割
- 1文あたり20字以内を意識する

Whisper側の癖を知り、原稿をそれに合わせた。  
ツールを使いこなすとは、ツール側の特性を先に理解すること。順番、間違えてる人多すぎ。

**③ コメント返信率が落ちた。**

これが最も想定外だった指標。  
自動投稿が動き始めると、「投稿した感覚」がなくなる。  
通知を確認する頻度が自然に落ちた。  
2週目以降、コメントへの返信が平均12時間以上遅れるようになった。

自動化の盲点。  
「送る」は自動にできる。「気づく」は自動にできない。

## このデータをどう使うか

2つの用途で活用できる。

**スタックの設計参考として。**  
表の各ステップは、それぞれ別のツールに置き換えられる。HeyGenをなくしてテキスト動画だけで運用することも可能。どこを自動化し、どこを手動にするかを判断するときの参考にしてほしい。

**「自動化で失うもの」を先に想定するために。**  
コメント返信の遅延は、運用前に気づけた問題だった。データを見てから対処するより、設計段階で「これは自動化しない」と先に決めておく方が早い。完全版では、30日後に筆者が実際に行った「残した自動化・手放した自動化」の仕分け結果を全データつきで公開している。
