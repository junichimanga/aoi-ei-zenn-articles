# Instagramをほぼ全自動で30日回した観測ノート

## 結論から言う

30日で28本のリールを投稿した。  
手動で触ったのは、初日の設定だけ。  
フォロワーは200から310に増えた。  
再生数は89〜1,240。日によってばらつきが大きい。

「自動化すれば伸びる」は嘘だった。  
「自動化しないと続かない」は本当だった。  
その記録を、数字ごと全部出す。

---

## 1. きっかけ

毎日投稿を手動でやっていた。  
台本を書いて、録画して、字幕を手で打って、キャプションを考えて、投稿する。  
1本あたり90分かかっていた。

3日で止まった。

「続けられない仕組みは、存在しないのと同じ。」そう判断して、全部を自動化することにした。  
目的は「楽をすること」ではない。「続けること」だ。

---

## 2. 仕組みの全体像（専門用語なし版）

ツール名を出さずに書く。

```
① AIアバターを使って、話している動画を生成する
      ↓
② 音声から、セリフのタイムスタンプを自動で取得する（約1円 / 90秒動画）
      ↓
③ セリフに合わせた字幕を動画に合成する
      ↓
④ 動画をクラウドにアップロードする
      ↓
⑤ Instagramに自動で投稿する
      ↓
⑥ WordPressに下書きとして保存する
```

人が触るのは、①の「何を話すか」を決める部分だけ。  
あとはコマンドひとつで動く。

ここからツール名を出す。

| 役割 | 使ったツール |
|---|---|
| AIアバター動画の生成 | HeyGen（Creatorプラン内） |
| 字幕タイムスタンプの取得 | Whisper（OpenAI音声認識API） |
| 字幕合成・動画レンダリング | Remotion（React製） |
| Instagram自動投稿 | Instagram Graph API |

実行コマンドはこれだけ。

```bash
npm run workflow -- "https://app.heygen.com/videos/<ID>" "タイトル" automation "AIツール"
```

HeyGenのWeb画面でアバター動画を生成し、URLをコピーして貼る。それだけ。

## 3. 日別ログ抜粋（30日から10日を選んだ）

| 日 | 再生数 | リーチ | 保存数 | 出来事 |
|---|---|---|---|---|
| Day 1 | 312 | 289 | 4 | 初投稿。想定より反応が早かった |
| Day 3 | 89 | 76 | 1 | 明らかに見られていない |
| Day 7 | 1,240 | 1,103 | 18 | 「AIで仕事を断る方法」が当たった |
| Day 10 | 143 | 131 | 2 | 普通の日 |
| Day 14 | 520 | 488 | 9 | 「時間泥棒」という言葉がフックになった |
| Day 18 | 0 | 0 | 0 | **投稿できなかった日（トークン期限切れ）** |
| Day 19 | 0 | 0 | 0 | **同上。2日間のブランク** |
| Day 21 | 388 | 361 | 6 | ハッシュタグを減らした日 |
| Day 28 | 741 | 682 | 11 | 「これをやめたら楽になった」テーマ |
| Day 30 | 294 | 270 | 5 | 最終日 |

**伸びた日の共通点。**  
タイトルに「断言」があった。「〜の方法」より「〜は要らない」の方が数字が動いた。

**伸びなかった日の共通点。**  
「役に立ちそう」なテーマ。役立つより、共感を取った日の方が保存数が重かった。

**止まった日（Day 18〜19）。**  
Instagramのアクセストークンが期限切れになった。  
Graph APIのトークンは60日で無効になる。通知はない。自分で管理するしかない。  
更新スクリプトを手動で走らせて復旧したが、2日間のブランクが発生した。  
これは自動化の盲点だった。今は60日前にリマインダーを設定している。

## 4. 30日の数字

| 指標 | Day 1時点 | Day 30時点 |
|---|---|---|
| フォロワー数 | 200 | 310 |
| 総投稿数（30日） | 0 | 28 |
| 平均再生数 / 本 | — | 約380 |
| 最高再生数 | — | 1,240 |
| 最低再生数 | — | 89 |
| 累計保存数 | — | 127 |

フォロワーが増えた日は、保存数が多かった日と重なっていた。  
再生数は「見つかるかどうか」の指標。  
保存数は「価値があるかどうか」の指標。  
この2つは別物だと理解した。

---

## 5. やめたこと・残したこと

**やめたこと。**

- キャプションに長文を書くこと → 3行に削った。読まれないから。
- ハッシュタグを30個つけること → 8〜10個に減らした。多すぎるとスパム扱いされる可能性がある。
- 「ためになる」を意識してテーマを決めること → 「自分が面白いと思うか」で決めるようにした。
- 投稿時間を毎日調整すること → 毎朝7:00固定にして、考えるのをやめた。

**残したこと。**

- 字幕付きリール形式 → 音なしで見ている人がいるから。
- WordPressへの自動下書き保存 → 後でブログ記事に転用できる。
- 1日1本のペース → 品質より継続性を優先した判断。

## 6. これから試すこと

**カバーサムネイルの差し替え。**  
今は動画の先頭フレームがそのままサムネイルになっている。  
「クリックされるかどうかはサムネイルが決める」という仮説を、次の10日間で検証する。

**Threads連携の追加。**  
リール投稿と同時に、Threadsへの告知テキストを自動生成する仕組みを試す。  
集客経路を1つから2つに増やす目的。

**テーマのパターン比較。**  
「断言型」と「問いかけ型」のどちらが再生数・保存数で差が出るか、2週間かけて比較する。

## まとめ

自動化で「楽になった」は本当。  
自動化で「伸びた」は嘘。

続けることで、初めてデータが集まる。  
データが集まって、初めて判断できる。  
判断した結果が、次の精度をつくる。

手動では続かなかった。だから自動化した。それだけ。  
仕組みより先に、続けることを選んだ。順番はそっちだった。
